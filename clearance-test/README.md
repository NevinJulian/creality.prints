# Clearance test

A plate with six holes and a 10 mm pin. Each hole is bigger than the pin by the clearance engraved next to it, measured per side. `.20` means a 10.4 mm hole.

## Print

- Both parts as exported, flat on the bed, no supports
- Same filament and settings as the real parts will use
- 0.2 mm layer height

## Reading the result

Push the pin into each hole with the chamfered end first.

- Too tight: doesn't go in or needs real force
- Press fit: goes in with firm pressure and stays
- Sliding fit: moves freely without wobbling
- Loose: wobbles

Moving parts like twist locks use the smallest clearance that still gives a sliding fit.
